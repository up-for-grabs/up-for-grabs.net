Este repositorio contiene el contenido para el  [Sitio web de Up-For-Grabs](https://up-for-grabs.net/), una lista de proyectos con tareas curadas para nuevos colaboradores.

## Enumere su proyecto.

Si conoce o es dueño de un proyecto que debe aparecer en Up for Grabs,
[Siga las instrucciones para abrir una solicitud de extracción.](docs/list-a-project.md)[Siga las instrucciones para abrir una solicitud de extracción].

## Contribuyendo

Si desea participar en el proyecto, por favor lea el
[Contribución.md](.github/CONTRIBUTING.md)[CONTRIBUTING.md] archivo como contiene:

 - Instrucciones para configurar su entorno
 - Orientación para las pruebas locales
 - Comandos a ejecutar para verificar los cambios
